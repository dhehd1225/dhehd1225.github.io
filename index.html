01

나드리 (Nadri)

한국을 방문한 외국인 관광객과 현지인을 매칭하는 플랫폼 — 장소가 아닌 사람과 경험을 연결

React Native Expo FastAPI PostgreSQL OpenAI API
문제
기존 관광 플랫폼은 장소 추천에 그침. 관광객이 진짜 현지 경험을 얻으려면 신뢰할 수 있는 사람과의 접점이 필요한데, 이를 연결하는 서비스가 없었음.
과정
앱 서비스로 시작 → 오픈 3주 전 가이드 매칭 모델로 피봇. 전단지 홍보 무반응의 원인을 "신뢰 근거 부재"로 직접 진단하고, 웹사이트·SNS에 호스트 검증 정보를 보강해 신뢰 기반을 구축. 직접 대면 접객이 효과적임을 확인해 오프라인 중심으로 전환. 팀장의 기능 추가 요청 대신 홍보·데이터 확보를 우선순위로 주장해 관철. 결제는 선입금과 서비스 완료 후 잔금으로 나눠 받는 구조로 운영해 거래 리스크를 구조적으로 관리.
기획 웹 개발 현장 영업
결과

회고
문제의 근본 원인을 데이터가 아니라 신뢰라는 관계적 요소에서 찾아야 할 때가 있다는 것을 배웠다. 리스크가 있는 거래일수록 문제가 커지기 전에 구조적으로 막는 장치 — 단계별 결제, 호스트 검증 정보 — 가 중요하다는 것을 체감했다.
