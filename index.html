Project 01

나드리 (Nadri)

한국을 방문한 외국인 관광객과 현지인을 매칭하는 플랫폼 — 장소가 아닌, 사람과 경험을 연결

React Native Expo FastAPI PostgreSQL OpenAI API
문제
기존 관광 플랫폼은 장소 추천에 그침. 관광객이 진짜 현지 경험을 얻으려면 신뢰할 수 있는 사람과의 접점이 필요한데, 이를 연결하는 서비스가 없었음.
과정
앱 서비스로 시작 → 오픈 3주 전 '가이드 매칭' 모델로 피봇. 전단지 홍보는 무반응이었으나 직접 대면 접객은 효과적 — 오프라인 중심으로 전환. 팀장의 기능 추가 요청 대신 홍보·데이터 확보를 우선순위로 주장해 관철.

Project 03

Stock AI Assistant

한국·미국 주식 시장을 자동 수집·분석해 텔레그램으로 리포트를 보내고 보유 종목의 손절·익절을 실시간 모니터링하는 퀀트 자동매매 시스템

Python APScheduler SQLite KIS API DART API Claude API Telegram Bot
